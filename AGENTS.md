# Instruções para o Codex — APL Educa

## Contexto
O APL Educa é uma plataforma de apoio à organização de visitas escolares à Academia Paraibana de Letras.

## Fonte de verdade
Leia `docs/APL_EDUCA_ESPECIFICACAO_MVP.md` antes de planejar ou implementar funcionalidades.

## Regras obrigatórias
- Não inventar requisitos funcionais ou regras de negócio.
- Não implementar funcionalidades fora da sprint solicitada.
- Não tratar regras provisórias como decisões homologadas.
- Identificar ambiguidades e solicitar esclarecimentos.
- Priorizar Angular 22, TypeScript, SCSS e Optimus UI.
- Utilizar componentes standalone e Angular Router.
- Não adicionar backend sem autorização.
- Não atualizar dependências sem necessidade e aprovação.
- Preservar as funcionalidades existentes.

## Processo de desenvolvimento
1. Ler a especificação.
2. Identificar os requisitos relacionados à tarefa.
3. Apresentar um plano de implementação.
4. Aguardar aprovação antes de alterar arquivos.
5. Implementar em pequenas etapas.
6. Executar testes e build.
7. Informar arquivos modificados, requisitos atendidos e pendências.

## Aprendizado
Explique as decisões técnicas de maneira didática, pois o desenvolvimento também é utilizado para estudar Angular.
